# Vespera Jewellers — E-commerce Prototype

A front-end e-commerce concept for a fine jewellery storefront, put together solo with AI coding assistants as a quick prototype in around 30 minutes.

## Live Demo
https://gauravkatariya2008-hub.github.io/prototype/

## Features
- Product catalog with search and category browsing
- Shopping cart with add/remove and running total
- Checkout flow with order summary
- Order handoff via WhatsApp message instead of a payment gateway

## Tech
Single-file HTML, CSS, and JavaScript. No backend — cart and catalog state are stored in the browser (localStorage).

## Stall Sales app (`/stall`)
A one-tap sales recorder for running a stall: https://gauravkatariya2008-hub.github.io/prototype/stall/

- Add products with price and (optional) stock quantity
- Tap products to build a bill, then tap **Cash** or **UPI** to save it
- Header shows today's total split into cash and UPI
- Undo last bill, switch a bill between Cash/UPI, delete a bill, per-product summary
- Excel (CSV) download, backup file download and restore
- Data is saved in the phone's browser (localStorage) and the page works offline after the first load

## Status
A fast prototype, not a production store — built in about 30 minutes to test how quickly a working storefront concept could be assembled with AI coding tools, and to get hands-on practice with the flow end to end.
